# UriNet

**Important note:** the source code is not yet published. This repository preserves the folder structure only, with placeholder files, for reference. The complete source will be published when mainnet launches.

However, the user manual is available right now in the /docs folder or on our homepage at https://urinet.org/



The next era of the internet belongs to AI agents doing real work for real people. Today those agents move through a world made for humans. They log in with borrowed passwords, click through screens built for eyes, and pretend to be the person they work for. It works, the same way typing really fast on a flip phone “worked.” It’s time to make way for the smartphone. UriNet is the rails built for agents themselves: an account of its own, a precise grant of authority from the person it serves, a network that checks every action before it runs, and a reputation that follows it. People stay in control. Agents get room to work.

## Layout

| Path | Contents |
|---|---|
| `proto/` | Protobuf definitions of the messages, queries, events, and state. The single source of truth for both Go and TypeScript. |
| `third_party/proto/cosmos-sdk/` | The Cosmos SDK protobuf definitions at the pinned tag, vendored for import resolution and TypeScript generation. |
| `chain/app/` | The app wiring: `app.go`, the AnteHandler, the message policies, the send restriction functions, Genesis validation, export, and upgrades. |
| `chain/x/<module>/` | The five modules, each in the layout of the SDK's `x/bank`. |
| `chain/cmd/urid/` | The chain binary: AutoCLI, the Genesis commands, and the UriNet signing commands. |
| `chain/signing/` | The Go signing library: credential keyring, signature bundle, dummy proofs. Shared by `urid`, the sponsor server, and the tests. Never imports `chain/x`. |
| `ts/proto/` | TypeScript types generated by buf. Never edited by hand. |
| `ts/sdk/` | The protocol client. |
| `ts/wallet-core/` | The wallet core logic and the adapter interfaces. |
| `admin-wallet/` | The Admin Wallet / Simulator, in the browser. |
| `indexer/` | The minimal indexer, in Go. |
| `sponsor/` | The sponsor and relayer server for testing, in Go. |
| `devnet/` | Docker Compose, the Genesis scripts, the devnet values, and the named test accounts with their test-only keys. |
| `e2e/` | End-to-end tests, scenario files, and the load generator. |
| `docs/` | Documentation. |
| `scripts/` | Vendoring, code generation, and CI helper scripts. |

Directories appear when their phase gives them content.

## Requirements

- Go, at the version `go.mod` names. A newer local Go downloads the exact toolchain automatically.
- Node.js 22 and pnpm, at the versions `.nvmrc` and `package.json` name.
- buf, for protobuf linting and generation. The Go plugins are pinned in `go.mod`; the TypeScript plugin is pinned in `package.json`.
- Docker with Compose, for the devnet.

## Common commands

```sh
make build                 # build urid into build/
make test                  # Go tests
make lint                  # Go lint, proto lint, dependency and SDK version checks, TypeScript typecheck
make proto-gen             # regenerate Go code from proto/
make ts-gen                # regenerate TypeScript code into ts/proto
make check-generated       # fail if generated code is out of date
make testid-check          # every canonical test ID of the current phase has a test
make ts-test               # TypeScript unit tests (ts/sdk, ts/wallet-core)
make diff-test             # Go and TypeScript differential tests over chain/signing/testdata
make ts-node-test          # the TypeScript packages against a real urid node (builds urid)
make devnet-up             # start the devnet
make e2e-smoke             # the end-to-end smoke test
```
